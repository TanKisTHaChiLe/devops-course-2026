1. Ветки:

Git — ветка это просто указатель на коммит (файл 41 байт), всё локально → мгновенно.

SVN — ветка это копия директории на сервере, нужна сеть → медленно.

2. Коммит без интернета в SVN — нельзя. SVN централизованный: коммит идёт сразу на сервер, полной истории локально нет.

3. Где SVN лучше:

большие бинарники (видео, CAD, PSD) — есть частичный checkout;

права доступа на уровне папок (в Git — только на весь репозиторий);

простой централизованный контроль для нетехнических команд;

старые legacy-проекты, где миграция дороже.
